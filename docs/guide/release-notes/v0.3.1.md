# Release Notes - Lap v0.3.1

Lap v0.3.1 makes library organization and photo review faster, safer, and easier to follow. It adds folder search and inline folder creation, improves duplicate and related-photo review, makes album scanning clearer, and strengthens preview, thumbnail, and AI-search reliability across more formats and platforms.

## 🚀 Highlights

- **Folder Search** — Search folders directly from the Albums sidebar. Matching folders retain their album-tree context, with root-folder visibility, clear highlighting, and favorite-folder filtering. (#260)
- **Improved Duplicate Review** — Duplicates and Similar Photos now support keep/unkeep actions, selected-item deletion, refresh and reanalyze controls, and more predictable group navigation.
- **Related Photo Grouping** — Configure a dedicated grouping strictness for Similar Photos, independent of the Find Similar Photos search setting. Exact duplicates are excluded from related-photo analysis.
- **Safer Album Management** — Removing an album now coordinates with active indexing to prevent file-database errors during background scans.
- **Clearer Scan Progress** — Album scans now report global progress through discovery, thumbnail generation, and search-data preparation, with detailed indexed, skipped, failed, and merged counts in Album Info.

## ✨ New Features and Improvements

- Added inline subfolder creation in the Albums tree, with automatic unique names and keyboard editing.
- Added folder favorite/unfavorite actions and folder file counts.
- Added collection editing from File Info; Collections is always visible and appears before Comment.
- Improved the Add to Collection dialog and collection-list management. (#245)
- Preserved the active collection and tags when using Save As.
- Added a subtle fade to dragged thumbnails and their drag ghost. (#266)
- Added adaptive Calendar heatmap levels for libraries with very different daily photo counts.
- Added search boxes to Smart Albums, Tags, People, and Albums views, with improved empty states.
- Updated welcome content to better introduce Albums, Smart Albums, and Collections.
- Improved grouped keyboard navigation and physical-key support for the Search shortcut on non-English keyboard layouts. (#259)
- Improved collection, Smart Album, and album ordering workflows.

## 🐞 Bug Fixes

- Fixed TIFF thumbnail and preview orientation/dimension handling, including vertical TIFF images.
- Fixed GIF preview playback restarting incorrectly when opening an image.
- Fixed Live Photo comparison viewport synchronization when HEIC and video dimensions differ.
- Fixed preview loading, image positioning, and macOS rename behavior.
- Fixed thumbnail and preview support for additional formats, including Phase One IIQ RAW files. (#253)
- Fixed macOS HEIF support by bundling the required library.
- Fixed manual folder refreshes missing child-folder reconciliation.
- Fixed folder copy and move operations so nested files remain indexed and thumbnail caches follow cross-album moves.
- Fixed renamed-folder recovery using filesystem inode tracking.
- Fixed QuickTime creation-date parsing with timezone offsets.
- Fixed related-photo group deletion and invalid one-item comparison actions.
- Fixed stale content, selection, and grouping updates after file save, move, or delete operations.
- Fixed multilingual AI-search model download validation and added clearer guidance when the default English-only model receives non-English queries. (#255)
